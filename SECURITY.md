# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or potential flaw in Muxella, Muxella, or its Named Pipe IPC protocol:
1. Please **do not** report security vulnerabilities through public GitHub issues.
2. Privately report vulnerabilities via GitHub Security Advisories or reach out directly to the repository maintainer.
3. Include details of the vulnerability, reproduction steps, and potential attack vectors (e.g. IPC pipe privilege boundaries).

We take security and system stability seriously and will acknowledge receipt and coordinate a patch promptly.
