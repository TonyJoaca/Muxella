## Clean-Room Engineering
Muxella is an independent, clean-room software implementation developed from published specifications, public documentation, and standard Windows SDK audio interfaces (WASAPI, MMCSS, Core Audio). 

- No proprietary binary files, disassemblies, or decompiled code were consulted, used, or incorporated into this software.
- All routing algorithms, lock-free ring buffers, Catmull-Rom cubic Hermite spline interpolation, and biquad DSP equations were independently derived and implemented.
